# Google Analytics 4

> Google Analytics 4 (GA4) is Google's event-based web and app analytics platform. Its API surface has three parts: the Data API (reporting), the Admin API (configuration), and the Measurement Protocol (server-side event ingest). Google publishes no OpenAPI and no llms.txt; it publishes Discovery documents on the API hosts, which is where the machine-readable contract actually lives.

Provenance: generated 2026-08-13 by the API Evangelist enrichment pipeline from apis.yml and the
artifacts in this repository. Google does not serve /llms.txt — developers.google.com/llms.txt,
developers.google.com/analytics/llms.txt and google.com/llms.txt all returned 404 on 2026-08-13.

## Read this first

- Auth is Google OAuth 2.0 only for the Data and Admin APIs. No API keys. Bearer token in the
  Authorization header. Authorization server: https://accounts.google.com
- Scopes: analytics.readonly (read), analytics (read+write data), analytics.edit (configuration),
  analytics.manage.users / analytics.manage.users.readonly (access bindings).
- Resources are addressed by full resource NAME, not bare id: `properties/1234567`, not `1234567`.
- Reporting operations are POST but read-only, and use the custom-method colon form:
  `POST /v1beta/properties/{property}:runReport`.
- There is NO idempotency key anywhere in GA4. Retrying a failed Admin API create can duplicate
  the resource. Read-before-write.
- There are NO rate-limit response headers. Set `returnPropertyQuota: true` on Data API requests
  to read your remaining budget in the response body, or call getPropertyQuotasSnapshot (v1alpha).
- Errors are google.rpc.Status, not RFC 9457. Branch on `error.status`, never on `error.message`.
- Retrying 500/503 without a cap will burn the server-error quota (10/hour standard) and lock the
  property out.

## APIs

- [Google Analytics Data API](https://developers.google.com/analytics/devguides/reporting/data/v1): reporting. Base https://analyticsdata.googleapis.com. v1beta (11 ops) and v1alpha (15 ops).
- [Google Analytics Admin API](https://developers.google.com/analytics/devguides/config/admin/v1): configuration. Base https://analyticsadmin.googleapis.com. v1beta (55 ops) and v1alpha (166 ops).
- [Measurement Protocol](https://developers.google.com/analytics/devguides/collection/protocol/ga4): server-side event ingest. POST https://www.google-analytics.com/mp/collect. Auth is an api_secret query parameter, not OAuth. Returns 204 with no body and never reports validation errors.

## Agent surface

- MCP: official server at https://github.com/googleanalytics/google-analytics-mcp, PyPI `analytics-mcp` 0.7.0. LOCAL STDIO ONLY — `pipx run analytics-mcp`. There is no hosted endpoint an agent can call. Seven read-only tools: get_account_summaries, get_property_details, list_google_ads_links, run_report, run_funnel_report, get_custom_dimensions_and_metrics, run_realtime_report.
- A2A agent card: none. /.well-known/agent-card.json returns 404 on all eight hosts.
- Webhooks: one narrow surface only — AudienceList / RecurringAudienceList state-change callbacks, v1alpha. No AsyncAPI.
